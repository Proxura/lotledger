What is a lot number, and how do you assign one?

A lot number is the code that ties a product back to its batch record. Here is how small makers assign one and what to keep behind it.

A lot number (or batch number) is a code you put on a product so you can trace it back to the batch it came from. It answers one question: which batch was this? From there you can find the date, the ingredients, the suppliers and how many units were made.

What goes in a lot number

Keep it short and unique. The simplest scheme that works: a prefix for your business and a number that goes up by one (or ten) with every batch. FW1040, FW1050, FW1060. Some makers encode the date (240302 for March 2, 2024) or the product. Both work, but a plain counter never collides and never needs explaining.

What the lot number points at

The number is only useful if there is a record behind it. For each lot, write down the product, the date made, the units made, the ingredients with their own supplier lot numbers, the best-by date, and then every movement out: sold, sampled, wasted, returned. That record is what an inspector means by "production records" and what you need the day a supplier recalls an ingredient.

Do cottage food producers need lot numbers?

Most state cottage food laws do not require a lot number on the label. Most do expect you to keep records and be able to trace a product back to its batch, and many programs recommend a batch code for exactly that reason. A lot number costs nothing to add to a label and makes the record useful.
