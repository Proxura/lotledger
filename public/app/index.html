Stripe

Stripe → Developers → Webhooks → Add destination → event checkout.session.completed. Stripe does not include line items in the event; either put them in the session's metadata.items ("2 x Lavender Bar Soap") or give LotLedger a restricted key below that can only read Checkout Sessions.

Shopify

Shopify → Settings → Notifications → Webhooks → Create webhook → Event "Order payment", format JSON.
